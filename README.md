# Carryover

**Shift continuity for the work that cannot be dropped.**

Carryover is a fictional plant-operations product case study organized around one accountable path:

`Observation → Carryover decision → Incoming acknowledgement → Assigned action → Resolution evidence → Updated operating record`

## Workspaces

- Overview — shift pressure, unresolved conditions, and incoming priorities.
- Handoffs — outgoing context, selected carryover records, and acknowledgements.
- Issues — searchable operating records with evidence and audit history.
- Actions — ownership, waiting approval, and evidence-backed closure.
- Reports — a filtered printable shift brief and CSV export.

The role-preview control demonstrates product permissions for Operator, Shift supervisor, and Plant manager. It is not authentication or security enforcement.

## Run

```bash
npm install
npm run dev
npm test
npm run build
```

All plants, people, equipment, incidents, actions, and records are fictional and unrelated to any real employer.
